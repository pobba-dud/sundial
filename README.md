# SUNDIAL — Game Promo Website

A responsive promotional website for **SUNDIAL**, a hypothetical narrative-driven game about memory, truth, and the cost of rewriting the world.

Live concept: in a reimagined, post-war Slovakia fractured by war and secrecy, Maria Araya searches for her missing father — a man erased from history by the mysterious Project Sundial. Every decision shapes the story.

## Features

- Hero section with animated title and particle background
- Scroll-reveal sections for the game's story and world
- Interactive character cards — click Maria, Lenka, or Kazi to open a full modal with biography, role, quote, and attribute stats
- Custom favicon / app-icon set and web manifest
- Fully static — no build step, no backend

## Tech

- **HTML, CSS, vanilla JavaScript**
- Animate.css for animations

## Run it

Just open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server
# then visit http://localhost:8000
```

## Status

Concept / portfolio site for a hypothetical game — the game itself is not in development from this repo.
